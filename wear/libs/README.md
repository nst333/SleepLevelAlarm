# Samsung Health Sensor SDK

Place Samsung's `samsung-health-sensor-api-1.4.1.aar` here. The local development copy was extracted from the SDK ZIP already in the owner's Downloads folder. The AAR is ignored by Git; it is not vendored or licensed by this project.

Download and follow Samsung's SDK terms: https://developer.samsung.com/health/sensor/overview.html

Real sensor testing requires Galaxy Watch4 or later with Health Sensor Service developer mode enabled. An emulator can validate UI and ordinary alarms, but cannot emulate Samsung's sensor service. Public distribution requires Samsung partner approval and registration of the release package/signature.
